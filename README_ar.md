# مترجمي — عربي ⇄ فرنسي (بدون إنترنت)

## الحصول على التطبيق بدون Android Studio (من الهاتف أو الحاسوب)
1. أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً اسمه Mutarjimi (Public).
2. ارفع كل محتويات هذا المجلد (Add file ← Upload files)، مع مجلدي `.github` و`app`.
3. افتح تبويب **Actions** ← **Build Mutarjimi APK** ← **Run workflow**، وانتظر 5 إلى 8 دقائق حتى تظهر علامة ✅.
4. افتح تبويب **Releases** على صفحة المستودع، ونزّل **Mutarjimi.apk**.
5. ثبّته على الهاتف، وإن طُلب السماح بالتثبيت من مصدر غير معروف فوافق.

**رابطك الثابت للتحميل** (غيّر USERNAME باسم حسابك):
`https://github.com/USERNAME/Mutarjimi/releases/latest/download/Mutarjimi.apk`
